> **I don't just play in the world of code — I build parts of it.**

I'm **SNMDESERT**, a Minecraft plugin developer and web developer who enjoys turning ambitious ideas into practical projects. From server-side systems and anti-cheat research to web platforms and admin dashboards, I like building things that solve real problems.
