# SNMDESERT GitHub Profile Setup

## Files
- `README.md` — profile page, neon pink/purple theme, animated typing, stats and language cards.
- `.github/workflows/snake.yml` — generates contribution snake SVGs and publishes them to the `output` branch.

## Install
1. On GitHub, create or open a **public repository named exactly `SNMDESERT`**.
2. Put `README.md` in the repository root.
3. Put `snake.yml` at `.github/workflows/snake.yml`.
4. Open **Settings → Actions → General** and ensure workflows are allowed to run. Under workflow permissions, allow read and write access to repository contents if required.
5. Open **Actions → Generate Contribution Snake → Run workflow**.
6. Once it succeeds, confirm the `output` branch contains the generated SVG files.

## Notes
- The README is arranged in the requested language order: Turkish, English, Azerbaijani.
- SNMAC is intentionally not included.
- GitHub stats and third-party animation services may take time to load or may occasionally be unavailable.
